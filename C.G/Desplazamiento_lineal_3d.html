Tecnologías utilizadas

Three.js r128

Librería JavaScript para renderizar gráficos 3D en el navegador. Maneja la escena, cámara, luces y objetos.

WebGL

API del navegador que usa la GPU del dispositivo para renderizar gráficos 3D con alta performance. Three.js lo usa internamente.

requestAnimationFrame

Función nativa del navegador que ejecuta el loop de animación a ~60 fps, sincronizado con la pantalla.

HTML Canvas

Elemento HTML que actúa como lienzo donde WebGL dibuja cada frame de la animación.
